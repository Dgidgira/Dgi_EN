# Настройки оформления документа Word

Файл: `extension/config/docx-styles.json`. После изменения обновите расширение на `chrome://extensions`, затем выгрузите документ заново.

Если значение указано неверно или пропущено, используется значение по умолчанию (указано в скобках), а в консоли страницы просмотра появляется предупреждение. Документ всё равно выгружается.

| Параметр | Что задаёт | Допустимые значения |
|----------|------------|---------------------|
| `fonts.body` | Шрифт основного текста («Calibri») | Название шрифта, установленного у читателя, до 64 символов |
| `fonts.headings` | Шрифт названия и заголовков шагов («Calibri») | То же |
| `sizesPt.title` | Размер названия инструкции, пт (20) | 6–72 |
| `sizesPt.heading` | Размер заголовков «Шаг N», пт (13) | 6–72 |
| `sizesPt.body` | Размер основного текста, пт (11) | 6–72 |
| `sizesPt.meta` | Размер строки с датой, пт (9) | 6–72 |
| `colors.title` | Цвет названия («1F2937») | Шесть шестнадцатеричных цифр без `#`, например `000000` |
| `colors.heading` | Цвет заголовков шагов («1F2937») | То же |
| `colors.body` | Цвет основного текста («1F2937») | То же |
| `colors.meta` | Цвет строки с датой («6B7280») | То же |
| `colors.stepNumber` | Цвет номера шага в группе («DC2626», как рамки на скриншотах) | То же |
| `page.size` | Размер страницы («A4») | `A4`, `Letter` |
| `page.orientation` | Ориентация («portrait») | `portrait` — книжная, `landscape` — альбомная |
| `page.marginsMm.top`, `right`, `bottom`, `left` | Поля страницы, мм (20, 15, 20, 20) | 0–100 |
| `spacing.afterParagraphPt` | Интервал после абзаца, пт (4) | 0–72 |
| `spacing.afterImagePt` | Интервал после скриншота, пт (14) | 0–72 |
| `spacing.beforeHeadingPt` | Интервал перед заголовком шага, пт (12) | 0–72 |
| `spacing.lineSpacing` | Межстрочный интервал (1.15) | 0.5–3 |
| `image.maxWidthPercent` | Наибольшая ширина скриншота, % ширины текста (100) | 10–100 |
| `image.border` | Тонкая рамка вокруг скриншота (true) | `true`, `false` |
| `image.borderColor` | Цвет рамки скриншота («D1D5DB») | Шесть шестнадцатеричных цифр без `#` |

Стили в документе называются «Title», «heading 1» (заголовки шагов, видны в области навигации Word), «Step Text», «Step Image», «Document Meta». Их можно дополнительно поменять в самом Word: изменения стиля применятся ко всем шагам сразу.
