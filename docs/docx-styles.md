# Настройки оформления документа Word

Файл: `extension/config/docx-styles.json`. После изменения обновите расширение на `chrome://extensions`, затем выгрузите документ заново. Те же настройки (шрифты, размеры, цвета, поля, отступы, подписи) применяются к выгрузке в HTML.

Значения по умолчанию повторяют корпоративный шаблон (стили «КИСУСС_…»): Times New Roman 12 pt, чёрный текст, одинарный интервал, абзацный отступ 1,25 см, выравнивание по ширине, поля 20 / 15 / 20 / 30 мм (верх / право / низ / лево), номер страницы по центру в верхнем колонтитуле. Подпись под скриншотом оформлена по ГОСТ 34 (через ГОСТ 2.105): «Рисунок 1 – Шаг 1», по центру, без точки в конце. Если автор создал разделы (FR-10), раздел — заголовок первого уровня «1 Название» (номер без точки), шаги и рисунки нумеруются внутри раздела: «Шаг 1.2», «Рисунок 1.2». Новый раздел с новой страницы не начинается.

Если значение указано неверно или пропущено, используется значение по умолчанию (указано в скобках), а в консоли страницы просмотра появляется предупреждение. Документ всё равно выгружается.

| Параметр | Что задаёт | Допустимые значения |
|----------|------------|---------------------|
| `fonts.body` | Шрифт основного текста («Times New Roman») | Название шрифта, установленного у читателя, до 64 символов |
| `fonts.headings` | Шрифт названия и заголовков шагов («Times New Roman») | То же |
| `sizesPt.title` | Размер названия инструкции, пт (13) | 6–72 |
| `sizesPt.section` | Размер заголовков разделов «1 Название», пт (13) | 6–72 |
| `sizesPt.heading` | Размер заголовков «Шаг N», пт (12) | 6–72 |
| `sizesPt.body` | Размер основного текста, пт (12) | 6–72 |
| `sizesPt.meta` | Размер строки с датой, пт (12) | 6–72 |
| `sizesPt.caption` | Размер подписи рисунка, пт (11) | 6–72 |
| `sizesPt.pageNumber` | Размер номера страницы, пт (10) | 6–72 |
| `colors.title` | Цвет названия («000000») | Шесть шестнадцатеричных цифр без `#`, например `1F2937` |
| `colors.heading` | Цвет заголовков шагов («000000») | То же |
| `colors.body` | Цвет основного текста («000000») | То же |
| `colors.meta` | Цвет строки с датой («000000») | То же |
| `colors.stepNumber` | Цвет номера шага в группе («000000»; номер всегда полужирный) | То же |
| `page.size` | Размер страницы («A4») | `A4`, `Letter` |
| `page.orientation` | Ориентация («portrait») | `portrait` — книжная, `landscape` — альбомная |
| `page.marginsMm.top`, `right`, `bottom`, `left` | Поля страницы, мм (20, 15, 20, 30) | 0–100 |
| `paragraph.align` | Выравнивание текста и заголовков шагов («justify») | `left`, `center`, `right`, `justify` — по ширине |
| `paragraph.firstLineIndentMm` | Абзацный отступ, мм (12.5) | 0–50 |
| `title.align` | Выравнивание названия и строки с датой («center») | `left`, `center`, `right`, `justify` |
| `spacing.afterParagraphPt` | Интервал после абзаца, пт (0) | 0–72 |
| `spacing.beforeSectionPt` | Интервал перед заголовком раздела, пт (18) | 0–72 |
| `spacing.beforeHeadingPt` | Интервал перед заголовком шага, пт (12) | 0–72 |
| `spacing.beforeImagePt` | Интервал перед скриншотом, пт (6) | 0–72 |
| `spacing.afterImagePt` | Интервал после скриншота (до подписи), пт (6) | 0–72 |
| `spacing.afterCaptionPt` | Интервал после подписи рисунка, пт (6) | 0–72 |
| `spacing.lineSpacing` | Межстрочный интервал (1) | 0.5–3 |
| `image.maxWidthPercent` | Наибольшая ширина скриншота, % ширины текста (100) | 10–100 |
| `image.border` | Тонкая рамка вокруг скриншота (true) | `true`, `false` |
| `image.borderColor` | Цвет рамки скриншота («D1D5DB») | Шесть шестнадцатеричных цифр без `#` |
| `image.captions` | Подписи «Рисунок N – Шаг K» под скриншотами (true) | `true`, `false` |
| `header.pageNumbers` | Номер страницы по центру в верхнем колонтитуле (true) | `true`, `false` |

Стили в документе Word и их прообразы в шаблоне:

| Стиль | Прообраз в шаблоне | Что оформляет |
|-------|--------------------|---------------|
| «Normal» | «КИСУСС_текст основной» | Основа для остальных стилей |
| «Title» | «КИСУСС_заголовок без номера» | Название инструкции |
| «Document Meta» | — | Строка с датой |
| «heading 1» | «КИСУСС_заголовок 1ур» / «КИСУСС_заголовок 2ур» | С разделами — заголовки разделов «1 Название»; без разделов — заголовки «Шаг N». Видны в области навигации Word |
| «heading 2» | «КИСУСС_заголовок 2ур» | Заголовки «Шаг 1.2», если в инструкции есть разделы |
| «Step Text» | «КИСУСС_текст основной» | Описания шагов |
| «Step Image» | «КИСУСС_рисунок положение» | Абзац со скриншотом |
| «caption» | «КИСУСС_рисунок название» | Подпись рисунка; номер — поле `SEQ Рисунок`, поэтому работает «Ссылки → Список иллюстраций». В разделах номер «2.3»: номер раздела — текстом, номер рисунка — `SEQ` с перезапуском в каждом разделе |
| «header» | «КИСУСС_колонтитул верхний» | Номер страницы |

Эти стили можно дополнительно поменять в самом Word: изменения стиля применятся ко всем шагам сразу.

Слово «Рисунок» в подписи хранится в строках интерфейса (`_locales/ru/messages.json`, `exportFigureLabel`).
