# Ручные проверки

Пока в спайке нет автотестов, каждая функция проверяется по шагам ниже. Используются только синтетические данные.

## Установка расширения
1. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.
4. После изменений в коде нажмите кнопку обновления на карточке расширения.

## MC-1. Каркас расширения: включение и выключение записи
Ожидаемый результат по каждому шагу указан после стрелки.

1. Установите расширение → на карточке нет ошибок, имя «Запись инструкций».
2. Закрепите значок расширения на панели и нажмите его → окно «Запись остановлена» с серой точкой, зелёная кнопка «Начать запись».
3. Нажмите «Начать запись» → текст «Идёт запись» красным с пульсирующей точкой, красная кнопка «Остановить запись», на значке красная метка «REC».
4. Закройте и снова откройте окно расширения → состояние «Идёт запись» сохранилось.
5. На карточке расширения нажмите ссылку «service worker», дождитесь его остановки (или перезапустите браузер) и снова откройте окно → состояние и метка «REC» сохранились.
6. Нажмите «Остановить запись» → «Запись остановлена», метка на значке пропала.
7. В консоли сервис-воркера и всплывающего окна (правый клик по окну → «Проверить») нет ошибок.

## MC-2. Запись шагов: клики, ввод, списки (FR-1, SQ-1, SQ-5)

**Подготовка**
1. Запустите локальный сервер с тестовыми страницами (только на этой машине):
   `python3 -m http.server 8000 --bind 127.0.0.1 --directory test-pages`
2. Обновите расширение на `chrome://extensions`. Chrome предупредит, что расширение получает доступ ко всем сайтам: это ожидаемо для спайка.
3. Откройте http://127.0.0.1:8000/forms.html. Если страница была открыта до обновления расширения, перезагрузите её.
4. Чтобы смотреть записанные шаги: на карточке расширения откройте «service worker» и в консоли выполните:
   ```js
   chrome.storage.local.get("steps").then(r => console.table(r.steps.map(s => ({ type: s.type, label: s.label, source: s.labelSource, value: s.value }))))
   ```
   Команда только читает шаги из локального хранилища расширения и выводит их таблицей; ничего не изменяет и никуда не отправляет.
   При первой вставке Chrome покажет предупреждение о вставке кода: введите в консоли `allow pasting`, нажмите Enter и вставьте команду снова. Это разовая защита Chrome от мошенничества, а не ошибка расширения.

**Проверка**
1. Не включая запись, кликните «Сохранить» → в окне расширения «Записано шагов: 0».
2. Нажмите «Начать запись», затем выполните действия ниже. После каждого ввода нажимайте Tab: значение поля записывается при уходе из поля.

| 2 | «Телефон заявителя»: ввести «+7 900 000-00-00» | input / Телефон заявителя / label / +7 900 000-00-00 |

| 4 | Поле «Без подписи»: ввести «123» | input / Без подписи / nearby-label / 123 (надпись стоит рядом, но не связана с полем) |
| 5 | «Пароль»: ввести «qwerty» | input / Пароль / label / *** |

3. В окне расширения «Записано шагов: 14», счётчик растёт во время записи.
4. Нажмите «Остановить запись», кликните «Сохранить» → шагов по-прежнему 14.
5. Снова «Начать запись» → счётчик сброшен на 0.
6. В консоли страницы и сервис-воркера нет ошибок.

## MC-3. Скриншоты с подсветкой элемента и страница просмотра (FR-2)

**Подготовка:** обновите расширение на `chrome://extensions`. Chrome может запросить подтверждение новых разрешений. Перезагрузите http://127.0.0.1:8000/forms.html.

1. Нажмите «Начать запись». Выполните действия 1, 6, 8, 10 и 11 из таблицы MC-2 (Фамилия, Тип происшествия, Есть пострадавшие, Сохранить, кнопка с принтером).
2. Прокрутите страницу вниз и нажмите «Кнопка внизу страницы».
3. Прокрутите страницу обратно вверх и нажмите ссылку «Справка».
4. В окне расширения нажмите «Открыть запись» → открывается вкладка «Просмотр записи» с 7 шагами.
5. Для каждого шага проверьте:
   - есть скриншот видимой части страницы на момент действия;
   - красная рамка точно обводит элемент, с которым работали (поле, список, чекбокс, кнопку);
   - для «Кнопка внизу страницы» рамка стоит на кнопке, а не в верхней части снимка;
   - у поля «Фамилия» на снимке уже введено значение; у «Тип происшествия» выбран «Пожар»; у чекбокса стоит галочка.
6. Не закрывая страницу просмотра, вернитесь на forms.html и нажмите «Сохранить» → на странице просмотра без перезагрузки появился шаг 8.
7. Быстро нажмите «Сохранить» 5 раз подряд → все 5 шагов записаны. Если у какого-то шага нет снимка, на его месте текст «Скриншот не сделан» с причиной: зафиксируйте, сколько таких шагов (ограничение Chrome: не больше 2 снимков в секунду).
8. Остановите запись, затем снова «Начать запись» → страница просмотра показывает «Шагов пока нет».
9. Проверьте масштаб: установите масштаб страницы 125% (Ctrl/Cmd и «+»), запишите клик по «Сохранить» → рамка совпадает с кнопкой.
10. В консолях сервис-воркера, страницы и страницы просмотра нет ошибок.

## MC-5. Ввод с отправкой по Enter: поиск (FR-1, FR-3)

Автоматическая часть: `osascript -l JavaScript tests/describe.test.js` → `OK: 24 проверок пройдено`.

1. Обновите расширение, перезагрузите forms.html, начните запись.
2. В поле «Поиск по карточкам» введите «пожар» и нажмите Enter → шаг «В поле «Поиск по карточкам» введите «пожар» и нажмите Enter».
3. Кликните в любое другое место страницы (поле теряет фокус) → новый шаг не появляется, повтора нет.
4. Снова кликните в поле поиска, допишите « ул. Тестовая» и нажмите Tab → шаг «В поле «Поиск по карточкам» введите «пожар ул. Тестовая»».
5. Внешний сайт с переходом на другую страницу: откройте поисковую систему, введите запрос и нажмите Enter → после перехода к результатам в записи есть шаг ввода с «и нажмите Enter». Зафиксируйте, что на скриншоте: страница до перехода (с введённым запросом) или уже результаты.
6. В поле «Описание» (многострочное) нажмите Enter внутри текста → отдельный шаг не появляется; шаг записывается только при уходе из поля.

## MC-6. Выпадающие списки и отсев шумных шагов (SQ-1, SQ-2, FR-4)

Автоматическая часть: `osascript -l JavaScript tests/normalize.test.js` → `OK: 20 проверок пройдено`.

**Подготовка:** обновите расширение, откройте http://127.0.0.1:8000/dropdowns.html (сервер из MC-2), начните запись и откройте «Просмотр записи» в соседней вкладке.

| № | Действие | Ожидаемый шаг в инструкции |
|---|----------|----------------------------|
| 1 | Раздел 1: откройте «Тип происшествия», выберите «ДТП» | В списке «Тип происшествия» выберите «ДТП» |
| 2 | Раздел 2: введите «ул», выберите «ул. Тестовая, 15» | В списке «Адрес происшествия» выберите «ул. Тестовая, 15» |
| 3 | Раздел 3: «Действия» → «Передать в службу» | В меню «Действия» выберите «Передать в службу» |
| 4 | Раздел 4: откройте «Служба реагирования», выберите «Полиция» | Два шага: «Нажмите «— выберите —»» и «Нажмите «Полиция»» (ожидаемое ограничение: список без ARIA не распознаётся) |
| 5 | Раздел 1: откройте список и закройте кликом мимо, ничего не выбирая | Шага нет |

**Проверьте:**
1. В инструкции 5 шагов, в сводке «Отсеяно шагов: 4».
2. У шагов 1–3 на скриншоте раскрытый список, красная рамка на выбранном варианте.
3. Внизу раскройте «Отсеянные шаги» → 4 шага с причинами: «открытие списка объединено с выбором варианта» (разделы 1 и 3), «текст для поиска в списке» (ввод «ул»), «список открыт, но вариант не выбран» (действие 5).
4. Если у действия 2 получилось «Выберите «ул. Тестовая, 15»» без названия поля или отдельный шаг ввода «ул», зафиксируйте: значит, поле не отдало значение до клика по подсказке.
5. У шага 2 раскройте «Технические подробности»: в конце адрес элемента, «+1» означает, что в шаг объединён 1 отсеянный шаг.
6. Скорость: повторите действия 1 и 3, выбирая вариант сразу после раскрытия (меньше чем через полсекунды) → на скриншоте всё равно раскрытый список, рамка на выбранном варианте. В «Технических подробностях» источник снимка: «снимок: action» (снимок по нажатию мыши успел) или «снимок: popup-open» (опоздал, взят запасной снимок раскрытого списка). «снимок: action-late» означает, что запасного снимка не нашлось: зафиксируйте такой случай.

**Шум на forms.html:**
7. Дважды быстро нажмите «Сохранить» → один шаг, в отсеянных «повторный клик по тому же элементу».
8. В «Фамилия» введите «Тест», Tab; вернитесь, допишите «ов», Tab → один шаг «В поле «Фамилия» введите «Тестов»», в отсеянных «промежуточный ввод».

**На реальных экранах (главное для SQ-1):** запишите выбор в нескольких списках вашей системы на Angular и отметьте для каждого: склеился ли он в один шаг, нашлось ли название поля. В «Технических подробностях» есть адрес и классы элемента: их достаточно, чтобы добавить правило под нераспознанный компонент.

## MC-7. Ручное маскирование полей (FR-6, SQ-6)

Автоматическая часть: `osascript -l JavaScript tests/mask.test.js` → `OK: 26 проверок пройдено`.

**Подготовка:** обновите расширение, перезагрузите forms.html, начните запись.

4. На скриншоте шага 1 нажмите на поле «Телефон заявителя» → «Скрыто полей: 1»; на всех скриншотах, где видно это поле, оно сильно размыто (символы не различить), включая снимки, сделанные до ввода телефона.
5. Описание шага 2: «В поле «Телефон заявителя» введите «***»»; в его «Технических подробностях» значение тоже «***».
6. На шаге с кнопкой внизу страницы поле телефона за пределами экрана → маски нет, лишних прямоугольников нет.
7. Нажмите на «Тип происшествия» → «Скрыто полей: 2», описание «В списке «Тип происшествия» выберите «***»», на скриншотах размыто поле списка.

9. Нажмите «Готово» → пунктирные области исчезли, размытие осталось. Перезагрузите страницу просмотра → маски сохранились.
10. Проверьте, что размытие захватывает весь текст поля, без чётких краёв букв, и что по размытому телефону нельзя угадать цифры. Проверьте при масштабе страницы 125%.
11. Начните новую запись → «Скрыто полей: 0».

**Поле под раскрытым списком:** на dropdowns.html раскройте «Тип происшествия» так, чтобы список лёг поверх поля «Адрес происшествия», и выберите вариант. В режиме скрытия отметьте «Адрес происшествия» → на скриншоте с раскрытым списком размыта только видимая часть поля, варианты списка читаются; пунктирная область тоже только по видимой части. На скриншотах без раскрытого списка поле размыто целиком.

**На странице выпадающих списков:** закройте поле «Адрес происшествия» и запишите выбор адреса → в инструкции «В списке «Адрес происшествия» выберите «***»», в отсеянных шагах введённый текст «ул» тоже скрыт.

**Аккуратность размытия:** у размытого поля нет светлой подложки и «лесенки» из полос; края скруглены; размытие не выходит заметно за рамку поля.

**Произвольные области (данные вне полей):**
1. Нажмите «Скрыть область» → подсказка про выделение, курсор над скриншотами — крестик; кнопка «Скрыть поля» снова доступна как обычная.
2. На скриншоте шага 1 выделите мышью прямоугольник вокруг заголовка «Карточка происшествия (тест)» → область размыта только на этом скриншоте, «Скрыто областей: 1».
3. На других скриншотах заголовок не размыт.
4. Выделите прямоугольник, частично выходящий за край скриншота → область обрезана по краю.
5. Короткий щелчок без движения мыши → область не создаётся.
6. Нажмите × на области → размытие убрано, «Скрыто областей: 0».
7. Создайте область, нажмите «Готово» → пунктир и × исчезли, размытие осталось; после перезагрузки страницы просмотра область на месте.
8. Начните новую запись → «Скрыто полей: 0 · Скрыто областей: 0».

**Ограничение:** область размывает только скриншот. Если те же данные попали в текст описания (например, подпись кнопки с ФИО), там они пока не скрываются.

4. На скриншоте группы видны все введённые значения (он сделан на последнем шаге группы). Номера шагов стоят снаружи рамок (обычно справа от поля) и не закрывают текст в полях.
5. У шага 3 в группе нажмите «Отделить» → группы «Шаги 1–2» и «Шаги 3–4».
6. Номера шагов при объединении и разделении не меняются.
7. Маскирование: скройте поле «Телефон заявителя» → на скриншоте группы оно размыто, в описании «***».
8. Прокрутка: уменьшите высоту окна браузера, чтобы страница прокручивалась. Начните новую запись, введите текст в «Описание», прокрутите страницу немного вниз (поле «Описание» должно остаться на экране) и отметьте «Есть пострадавшие». В режиме «Скрыть область» нажмите × на этой области → размытие пропало и на общем скриншоте, и у шага 1 после разделения.
10. Перезагрузите страницу просмотра → объединение сохранилось. Начните новую запись → объединение сброшено.

## MC-9. Кадрирование скриншота (FR-7)

Автоматическая часть: `osascript -l JavaScript tests/crop.test.js` → `OK: 21 проверок пройдено`.

**Подготовка:** обновите расширение, откройте «Просмотр записи» с несколькими шагами (можно объединёнными).

1. Под каждым скриншотом кнопка «Кадрировать». Нажмите → окно «Кадрирование скриншота»: снимок с белой рамкой по краям, сетка третей, 8 маркеров (углы и середины сторон), внизу пропорции «Свободно / Исходные / 1:1 / 4:3 / 16:9» и кнопки «Сбросить», «Отмена», «Применить».
2. Потяните правый нижний угол внутрь → рамка уменьшается, область вне рамки затемнена. Потяните верхнюю сторону вниз → меняется только высота.
3. Потяните за середину рамки → рамка двигается целиком и не выходит за края снимка.
4. Рамку нельзя сделать меньше 5% снимка и нельзя протащить маркер за противоположную сторону.
5. Выберите «16:9» → рамка принимает пропорции 16:9 внутри прежней; при перетаскивании угла пропорции сохраняются. «Свободно» снимает ограничение.
6. Нажмите «Применить» → в карточке показан только кадр, в том же масштабе, что и снимок; кнопка стала «Изменить кадр». Рамки шагов, размытие полей и областей стоят на своих местах внутри кадра.
7. Сделайте кадр, в который не попадает элемент шага → у шага пометка «(рамка шага вне кадра)».
8. «Изменить кадр» → «Сбросить» → «Применить» → снова весь снимок, кнопка «Кадрировать».
9. «Отмена» и клавиша Esc закрывают окно без изменений; Enter применяет кадр.
10. В режиме «Скрыть область» на кадрированном снимке выделите прямоугольник → область размыта точно там, где выделена.
11. Перезагрузите страницу просмотра → кадр сохранился. Начните новую запись → кадры сброшены.
