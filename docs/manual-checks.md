# Ручные проверки

Пока в спайке нет автотестов, каждая функция проверяется по шагам ниже. Используются только синтетические данные.

## Установка расширения
1. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.
4. После изменений в коде нажмите кнопку обновления на карточке расширения.

## MC-1. Каркас расширения: включение и выключение записи
Ожидаемый результат по каждому шагу указан после стрелки.

1. Установите расширение → на карточке нет ошибок, имя «Запись инструкций».
2. Закрепите значок расширения на панели и нажмите его → окно «Запись остановлена» с серой точкой, зелёная кнопка «Начать запись».
3. Нажмите «Начать запись» → текст «Идёт запись» красным с пульсирующей точкой, красная кнопка «Остановить запись», на значке красная метка «REC».
4. Закройте и снова откройте окно расширения → состояние «Идёт запись» сохранилось.
5. На карточке расширения нажмите ссылку «service worker», дождитесь его остановки (или перезапустите браузер) и снова откройте окно → состояние и метка «REC» сохранились.
6. Нажмите «Остановить запись» → «Запись остановлена», метка на значке пропала.
7. В консоли сервис-воркера и всплывающего окна (правый клик по окну → «Проверить») нет ошибок.

## MC-2. Запись шагов: клики, ввод, списки (FR-1, SQ-1, SQ-5)

**Подготовка**
1. Запустите локальный сервер с тестовыми страницами (только на этой машине):
   `python3 -m http.server 8000 --bind 127.0.0.1 --directory test-pages`
2. Обновите расширение на `chrome://extensions`. Chrome предупредит, что расширение получает доступ ко всем сайтам: это ожидаемо для спайка.
3. Откройте http://127.0.0.1:8000/forms.html. Если страница была открыта до обновления расширения, перезагрузите её.
4. Чтобы смотреть записанные шаги: на карточке расширения откройте «service worker» и в консоли выполните:
   ```js
   chrome.storage.local.get("steps").then(r => console.table(r.steps.map(s => ({ type: s.type, label: s.label, source: s.labelSource, value: s.value }))))
   ```
   Команда только читает шаги из локального хранилища расширения и выводит их таблицей; ничего не изменяет и никуда не отправляет.
   При первой вставке Chrome покажет предупреждение о вставке кода: введите в консоли `allow pasting`, нажмите Enter и вставьте команду снова. Это разовая защита Chrome от мошенничества, а не ошибка расширения.

**Проверка**
1. Не включая запись, кликните «Сохранить» → в окне расширения «Записано шагов: 0».
2. Нажмите «Начать запись», затем выполните действия ниже. После каждого ввода нажимайте Tab: значение поля записывается при уходе из поля.

| № | Действие | Ожидаемый шаг: type / label / source / value |
|---|----------|----------------------------------------------|
| 1 | «Фамилия»: ввести «Тестов» | input / Фамилия / label / Тестов |
| 2 | «Телефон заявителя»: ввести «+7 900 000-00-00» | input / Телефон заявителя / label / +7 900 000-00-00 |
| 3 | Поле с подсказкой «Адрес происшествия»: ввести «ул. Тестовая, 1» | input / Адрес происшествия / placeholder / ул. Тестовая, 1 |
| 4 | Поле «Без подписи»: ввести «123» | input / Без подписи / nearby-label / 123 (надпись стоит рядом, но не связана с полем) |
| 5 | «Пароль»: ввести «qwerty» | input / Пароль / label / *** |
| 6 | «Тип происшествия»: выбрать «Пожар» | select / Тип происшествия / label / Пожар |
| 7 | «Описание»: ввести «Тестовое описание» | input / Описание / label / Тестовое описание |
| 8 | Кликнуть по тексту «Есть пострадавшие» | checkbox / Есть пострадавшие / label / true |
| 9 | Выбрать приоритет «Высокий» | radio / Высокий / label / true |
| 10 | Кнопка «Сохранить» | click / Сохранить / text / null |
| 11 | Кнопка с принтером | click / Распечатать карточку / aria-label / null |
| 12 | «Передать в службу» | click / Передать в службу / text / null |
| 13 | Ссылка «Справка» | click / Справка / text / null |
| 14 | «Нестандартная кнопка» | click / Нестандартная кнопка / text / null |
| 15 | Клик по серой пустой области | шаг не записывается |
| 16 | Клик в поле «Фамилия» без изменения текста | шаг не записывается |

3. В окне расширения «Записано шагов: 14», счётчик растёт во время записи.
4. Нажмите «Остановить запись», кликните «Сохранить» → шагов по-прежнему 14.
5. Снова «Начать запись» → счётчик сброшен на 0.
6. В консоли страницы и сервис-воркера нет ошибок.

## MC-3. Скриншоты с подсветкой элемента и страница просмотра (FR-2)

**Подготовка:** обновите расширение на `chrome://extensions`. Chrome может запросить подтверждение новых разрешений. Перезагрузите http://127.0.0.1:8000/forms.html.

1. Нажмите «Начать запись». Выполните действия 1, 6, 8, 10 и 11 из таблицы MC-2 (Фамилия, Тип происшествия, Есть пострадавшие, Сохранить, кнопка с принтером).
2. Прокрутите страницу вниз и нажмите «Кнопка внизу страницы».
3. Прокрутите страницу обратно вверх и нажмите ссылку «Справка».
4. В окне расширения нажмите «Открыть запись» → открывается вкладка «Просмотр записи» с 7 шагами.
5. Для каждого шага проверьте:
   - есть скриншот видимой части страницы на момент действия;
   - красная рамка точно обводит элемент, с которым работали (поле, список, чекбокс, кнопку);
   - для «Кнопка внизу страницы» рамка стоит на кнопке, а не в верхней части снимка;
   - у поля «Фамилия» на снимке уже введено значение; у «Тип происшествия» выбран «Пожар»; у чекбокса стоит галочка.
6. Не закрывая страницу просмотра, вернитесь на forms.html и нажмите «Сохранить» → на странице просмотра без перезагрузки появился шаг 8.
7. Быстро нажмите «Сохранить» 5 раз подряд → все 5 шагов записаны. Если у какого-то шага нет снимка, на его месте текст «Скриншот не сделан» с причиной: зафиксируйте, сколько таких шагов (ограничение Chrome: не больше 2 снимков в секунду).
8. Остановите запись, затем снова «Начать запись» → страница просмотра показывает «Шагов пока нет».
9. Проверьте масштаб: установите масштаб страницы 125% (Ctrl/Cmd и «+»), запишите клик по «Сохранить» → рамка совпадает с кнопкой.
10. В консолях сервис-воркера, страницы и страницы просмотра нет ошибок.

## MC-4. Шаблонные описания шагов (FR-3, SQ-5)

Логика шаблонов проверяется автоматически: `osascript -l JavaScript tests/describe.test.js` → `OK: 20 проверок пройдено`. Ручная проверка подтверждает, что описания так же работают в расширении.

1. Обновите расширение, перезагрузите forms.html, начните запись и пройдите действия 1–14 из таблицы MC-2.
2. Откройте «Просмотр записи». Ожидаемые описания шагов:

| № | Описание |
|---|----------|
| 1 | В поле «Фамилия» введите «Тестов» |
| 2 | В поле «Телефон заявителя» введите «+7 900 000-00-00» |
| 3 | В поле «Адрес происшествия» введите «ул. Тестовая, 1» |
| 4 | В поле «Без подписи» введите «123» |
| 5 | В поле «Пароль» введите пароль |
| 6 | В списке «Тип происшествия» выберите «Пожар» |
| 7 | В поле «Описание» введите «Тестовое описание» |
| 8 | Отметьте «Есть пострадавшие» |
| 9 | Выберите вариант «Высокий» |
| 10 | Нажмите кнопку «Сохранить» |
| 11 | Нажмите кнопку «Распечатать карточку» |
| 12 | Нажмите кнопку «Передать в службу» |
| 13 | Перейдите по ссылке «Справка» |
| 14 | Нажмите «Нестандартная кнопка» |

3. Над списком: «Описаний с подписью элемента: 14 из 14» (у шага 4 подпись найдена рядом с полем, источник nearby-label).
4. Снимите галочку «Есть пострадавшие» → новый шаг «Снимите отметку «Есть пострадавшие»».
5. Сотрите текст в поле «Фамилия» и нажмите Tab → «Очистите поле «Фамилия»».
6. Раскройте «Технические подробности» у любого шага → видны тип действия, подпись, значение, источник подписи и адрес страницы.

## MC-5. Ввод с отправкой по Enter: поиск (FR-1, FR-3)

Автоматическая часть: `osascript -l JavaScript tests/describe.test.js` → `OK: 24 проверок пройдено`.

1. Обновите расширение, перезагрузите forms.html, начните запись.
2. В поле «Поиск по карточкам» введите «пожар» и нажмите Enter → шаг «В поле «Поиск по карточкам» введите «пожар» и нажмите Enter».
3. Кликните в любое другое место страницы (поле теряет фокус) → новый шаг не появляется, повтора нет.
4. Снова кликните в поле поиска, допишите « ул. Тестовая» и нажмите Tab → шаг «В поле «Поиск по карточкам» введите «пожар ул. Тестовая»».
5. Внешний сайт с переходом на другую страницу: откройте поисковую систему, введите запрос и нажмите Enter → после перехода к результатам в записи есть шаг ввода с «и нажмите Enter». Зафиксируйте, что на скриншоте: страница до перехода (с введённым запросом) или уже результаты.
6. В поле «Описание» (многострочное) нажмите Enter внутри текста → отдельный шаг не появляется; шаг записывается только при уходе из поля.
7. Ввод в адресную строку браузера не записывается: это интерфейс Chrome, расширения к нему доступа не имеют.
